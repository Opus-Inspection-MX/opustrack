# Iniciar y finalizar un viaje

Registre la salida y el regreso de un vehículo con las lecturas y fotografías del odómetro.

## Quién puede hacerlo

Personas con acceso a Viajes y permiso para registrar el recorrido correspondiente.

## Antes de comenzar

Identifique el vehículo y tenga disponible una fotografía legible del odómetro. Para capturar ubicación, el navegador solicitará permiso de localización.

## Pasos

1. Abra Viajes y seleccione Iniciar Viaje.
2. Seleccione el vehículo. Si el recorrido corresponde a una asignación, puede vincularla en el formulario.
3. Escriba el Odómetro Inicial (km) y agregue la Foto del Odómetro. Use Capturar GPS si va a registrar la ubicación.
4. Pulse Iniciar Viaje y compruebe que el recorrido quedó registrado antes de salir de la pantalla.
5. Al regresar, abra el detalle del recorrido y seleccione Finalizar Viaje.
6. Escriba el Odómetro Final (km), agregue la fotografía final y revise los datos de ubicación disponibles. Pulse Finalizar Viaje y compruebe el cierre.

## Resultado esperado

El viaje conserva los datos de salida y regreso. La lectura final debe ser igual o mayor que la inicial.

## Si no puede continuar

- Si la lectura no es aceptada, compruebe el vehículo seleccionado y los kilómetros reales. No cambie las lecturas para forzar el registro.
- Si no se captura ubicación, revise el permiso de localización del navegador y el mensaje mostrado.
- Si hay un error de conexión, compruebe si el viaje ya aparece registrado antes de iniciar otro. Conserve la captura y reintente desde el mismo formulario cuando sea posible.
