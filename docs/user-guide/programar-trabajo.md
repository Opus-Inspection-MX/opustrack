# Programar y asignar trabajo

Asigne técnicos a un incidente y registre la fecha prevista de atención.

## Quién puede hacerlo

Personal con acceso a Asignaciones y permiso para crear asignaciones. Las pantallas de Programación requieren sus propios permisos.

## Antes de comenzar

El incidente debe existir y estar disponible para su cuenta. Confirme qué técnicos atenderán el trabajo y, si conoce la fecha, revise su disponibilidad.

## Pasos

1. Abra Asignaciones y entre al formulario de nueva asignación.
2. Seleccione el Incidente al que corresponde el trabajo.
3. En Asignados, seleccione los técnicos responsables.
4. Escriba las Notas necesarias y, si corresponde, indique la Fecha programada (opcional).
5. Pulse Crear Asignación y compruebe en la lista o en el detalle que se guardaron el incidente, los responsables y la fecha.

## Resultado esperado

La asignación queda disponible para su seguimiento y para el trabajo de los técnicos asignados. El estado lo administra el sistema a partir de las acciones del trabajo; no se selecciona manualmente en este formulario.

## Programación y asignaciones

La Fecha programada de una asignación no sustituye la gestión del calendario. Programación permite consultar programaciones; Asignación de Programación permite trabajar con sus incidentes mediante Seleccionar Programación. Use estas pantallas cuando necesite gestionar el calendario, además de asignar responsables.

## Si no puede continuar

- Si falta un incidente o un técnico, revise que esté disponible para su cuenta y solicite apoyo al administrador.
- Si establece una fecha, los técnicos no pueden tener vacaciones aprobadas ni un día festivo en esa fecha. Cambie la fecha o los responsables según corresponda.
- Si el sistema rechaza la operación, revise el mensaje antes de intentarlo de nuevo. No cree otro incidente para eludir la restricción.
